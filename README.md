# Taller de Nochebuena · Catálogo Navidad 2026

Catálogo web estático de adornos navideños para pedidos por cantidad.

- Pedido mínimo: $300.000 (se pueden combinar productos)
- Seña del 15% (transferencia o efectivo)
- Entrega a domicilio, sin envíos por correo
- Los pedidos se hacen únicamente por WhatsApp

## Archivos
- `index.html`: página completa (HTML + CSS + JS)
- `img/`: fotos de los productos

## Configuración (en el bloque `<script>` de `index.html`)
- `WA_NUMBER`: número de WhatsApp
- `MIN_ORDER` y `DEPOSIT`: pedido mínimo y porcentaje de seña
- `PRODUCTS`: productos y precios
