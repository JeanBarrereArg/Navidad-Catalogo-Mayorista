# Taller de Nochebuena · Catálogo Navidad 2026

Catálogo web estático de adornos navideños. Los pedidos se hacen únicamente por WhatsApp.

- `index.html`: página completa (HTML + CSS + JS)
- `img/`: fotos de los productos

## Configuración
El número de WhatsApp está en la constante `WA_NUMBER`, al inicio del bloque `<script>` de `index.html`.
